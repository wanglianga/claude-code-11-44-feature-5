# 装载分区温度观测覆盖分析

一辆冷藏车的温度曲线全程合格，不代表每批货都被有效观测。本模块按
**批次 × 运输时段** 回答三个问题：哪些货物空间有合格测量支持、哪些没有
覆盖、哪些支持记录彼此矛盾。输出止于观测覆盖，不提供药品使用决定或装车
操作。

## 输入与坐标系

| 输入 | 表 | 说明 |
| --- | --- | --- |
| 车厢布局 | `vehicle_layout` | 本地坐标系（原点/方向/单位随布局提供）、厢体尺寸、货层、分区；更正产生新修订 |
| 托盘装载清单 | `pallet_placement` | 批次、托盘、占用矩形、货层、生效/结束时刻（可为范围）；更正产生新版本 |
| 隔板位置 | `partition_event` | 隔板在有效区间内的 x 位置，把车厢切成封闭分区 |
| 探头安装位置 | `probe_installation` | 探头安装点（含货层）与有效区间 |
| 分区验证资料 | `zone_validation` | 虚构验证：安装条件、已验证代表矩形、适用车厢结构、隔板配置、有效时间；可修订/撤回 |
| 批次温控规格 | `batch_spec` | 温度上下限、统计时间窗、窗口内最少有效读数 |
| 标准读数 | 既有 `reading_version` | 当前索引中归属本车、质量合格的读数 |

所有矩形统一为车厢本地坐标 `{x, y, w, h}`（米，轴对齐）。通过布局提供的
坐标系把托盘占用区域与探头代表范围放到同一平面，再按**货层**与**封闭分区**
区分隔离空间：隔板两侧、不同货层、另一辆同车型车辆的验证范围都不能混用
（验证记录绑定 `vehicle_id`、货层与隔板配置，配置不符即无资格）。

## 方法选择：精确空间切分（exact）

两种方法都能提供有依据的覆盖边界：

**本实现选择精确空间切分。** 托盘边界、探头代表范围、隔板位置都是轴对齐
矩形，把所有矩形边投影到 x/y 轴得到分片网格，每个分片内类别均质，面积
精确、可用矩形样本手算核对，适合需要精细定位的复核。

- **代价**：多次移动与大量重叠会使分片数随矩形边数平方增长，大批量重算
  耗时更长、差异展示更重；仓库定位与数据复核要等待精确切分完成（本演示
  规模下为毫秒级，但批次多、移动多时成本上升）。
- **另一种方式（固定网格保守覆盖）适用的条件**：车队规模大、需要批量
  扫描且成本要可控、可接受比例区间的场景。它只把整个格子都有相同资格
  且读数相容的格子计入确定覆盖，边缘格子保留未确认，同时显示由网格精度
  造成的 [确定, 确定+待核] 比例区间；批量分析更容易控制成本，但会把一些
  实际已覆盖的小区域留作待核。**任何情况下都不能用格子中心点命中就宣称
  整格覆盖**——保守网格的确定覆盖必须整格同资格且读数相容。

## 类别与不变式

类别互斥（一块空间在一个布局区间内只属于一个类别），总面积不超过完整
货物区域；多种原因并存时保留全部原因（`reasons`），不把未知部分计为正常，
也不把多种原因简单相加超过整体。

| 类别 | 含义 |
| --- | --- |
| `supported` | 有观测支持：≥1 个有资格探头在窗口内有效读数足够且结论一致（`reading_verdict` 标记 normal/exceed；一致只是多项支持，不增加面积） |
| `conflict` | 观测冲突：≥2 个有资格探头同域读数一超限一正常，显示冲突区域与两个物理读数，不能平均后宣布合格 |
| `no_reading` | 空间有资格但窗口内有效读数不足；不能用窗口外的一条正常读数填满整个窗口 |
| `no_qualification` | 缺少验证资格（未确认）；有探头在测但无对应布局验证时展示探头实际测量点，点观测不等同整块区域 |
| `layout_pending` | 移动时刻只有范围：各可行布局都一致的空间给确定覆盖，其余列为布局待核（附各可行布局的类别） |

空间占用冲突（两份装载清单把同一空间分给不同托盘）单独标记
`occupancy_conflict`，**不纳入覆盖率分母**——两份货量不能同时进入分母。

规则细节：

- 代表范围只来自验证资料，不由最近距离或温度看起来稳定就自行扩张。
- 多个有效探头的代表范围先取空间并集再计算覆盖，交叠不重复增加面积，
  覆盖比例不超过完整货物区域。
- 一个托盘含多个批次且没有批内可验证分区时，只说明托盘共同覆盖范围
  （`mixed_pallet`），不按件数比例虚构某批次位于靠门一侧。
- 装载清单、隔板位置、探头安装、范围资格任一变化，都在有效时刻切开
  分析区间；同一窗口内有效读数不足时保留空间上有资格但时间上缺观测的
  区域。

## 运行、更正与影响

- 每次分析是一个 `coverage_run`，记录输入版本指纹（布局/清单/验证/探头/
  隔板修订计数 + 读数水位）与实际引用的记录键（`used`）。
- 计算期间又收到位置更正时，输出必须说明所用布局：运行标记
  `stale_inputs`，过期结果不能直接替换当前分析；此前导出的结果
  （`coverage_export`）保留依据并能查到更正范围。
- 布局更正可能让原先有覆盖的货物失去资格；范围撤回（单个或按同一验证
  条件批量撤回）可能波及多次运输。影响查询按实际引用追到货物批次与分析
  时段，并包含原本未确认、补证后才获得资格的记录（导入新验证时随响应
  返回 `qualification_impact`）。

## 演示场景（2026-11-15，VH-01，6.0m × 2.0m）

坐标：原点 = 车厢最内侧左角地板，x 指向门口，y 指向右侧，单位米。
隔板 D1：09:00–13:00 在 x=3.0，13:00 起移到 x=4.0。
探头：PRB-1001@(0.5,1.0) 全程；PRB-2002@(2.5,1.0) 10:00–12:00（之后迁往 VH-02）。

| 场景 | 数据 | 手算结果 |
| --- | --- | --- |
| 门侧未覆盖 | P4 [5,6] 无验证 | 各窗口 `no_qualification` 2.0 m²·h |
| 范围交叠 | VAL-001[0,3] 与 VAL-002[2,3] 交叠 [2,3] | 并集不重复计量，P3 面积只算一次 |
| 托盘混批 | P3 [2,3] 含 LOT-A+LOT-B | 两批次看到同一托盘共同覆盖，`mixed_pallet` |
| 隔板变动 | D1 13:00 移到 4.0 | 13:00 起 D1@3.0 的验证失效，VAL-005（D1@4.0）接替 |
| 探头迁移 | PRB-2002 12:00 离车 | 12:00 后 [2,3] 只剩 VAL-001 资格 |
| 布局时刻不确定 | P5 移动时刻 [11:00,11:20] | [1,2] 与 [4,5] 各 2m²×1/3h 列 `layout_pending` |
| 同域读数冲突 | 11:20 PRB-1001=4.6°C 与 PRB-2002=9.6125°C | P3 [2,3] 窗口 11:00 `conflict` 2.0 m²·h，显示两个读数 |
| 缺时间窗口读数 | 09:00–10:00 无读数 | 有资格但 `no_reading`，不用 10:05 读数回填 |
| 批量撤回验证 | CAL-B 组（VAL-002/003）10:30 起撤回 | 10:00 窗口冲突减半、P2 失去资格；影响追到 LOT-A/B 各窗口 |
| 补证 | VAL-004 [5,6] 12:00–13:00 | 门侧 P4 在 12:00 窗口获得资格，13:00 起再次未确认 |
| 占用冲突 | MF-02 的 P9 [1.5,2.5] 与 P5/P3 重叠 | 冲突 2.0 m²·h 单独标记，不进入分母 |

## 验证

`backend/tests/test_coverage.py` 用手算可核对的矩形样本逐一核对上述场景：
空间并集（交叠不重复计量）、冲突交集、布局待核、占用冲突不计入分母、
重复导入不复制货物空间、范围修订/撤回的影响追踪、大批量重算稳定
（未确认区域不会变成正常）、运行守卫（计算期间输入变化 → stale_inputs）。
